# Excel-sales-performance-analysis
Excel-based sales performance analysis using SUMIF, XLOOKUP, Pivot Tables/Charts, Goal Seek, and VBA macros to derive business insights.
## Key Insights
- Best-performing region: East (₹4,00,000 in sales)
- Best-selling product: Laptop
- Top-performing employee: Ajay (₹1,50,000 in sales)
- A 40% increase in average sales is needed to reach the ₹7,00,000 target

## Tools & Techniques Used
- SUMIF, COUNTIF, RANK
- XLOOKUP for employee search
- Pivot Tables and Pivot Charts
- Goal Seek & What-If Analysis
- VBA Macro with button trigger
